# Algorithms HW #5-2: Minimum Spanning Tress
- Author: Yeonjun Kim (2024-13755)
- Date: 2025-11-20
- Programmed and tested in Arch Linux environment.

## Features
- Data structures for the algorithms
    - MinHeap, FiboHeap class (in `heap.py`)
    - UnionFind class (in `unionfind.py`)
- Kruskal's algorithm
- Prim's algorithm (using Min Heap and Fibonacci Heap)

## How to run
- Before running the program, you should place `input.txt` in this directory. In `input.txt`, you write N, M, and the graph edges.
- You can run the program by `$ python3 202413755_Task5.py`, and see the results in `output_kruskal.txt`, `output_prim.txt`, and `output_prim_fibo.txt`.
